# 旅行规划指南

> 千里奔赴山海约，万般风景皆在路上。

一份出行 checklist：从定目的地到收拾行囊，按部就班，少留遗憾。
走过的城市都标记在 [探索地图](/travel/map) 里。

## 一、定行程

- **为什么去**：刷[比赛日历](/calendar/2026-a)报名外地赛事，顺便把城市玩了；或挑一个没去过的地方
- **什么时候去**：春秋最舒服；夏天往海边、高原走，冬天往南走
- **去几天**：周末特种兵 2 天，深度漫游 5~7 天
- **怎么做功课**：高德 / 百度地图查距离和路线，小红书、马蜂窝抄作业，大众点评找吃的

## 二、交通

| 方式 | 建议 |
| --- | --- |
| 自驾 | 出发前检查轮胎、刹车、油量，导航设置好车牌避开限行；长途每 2 小时进服务区休息防疲劳；提前查目的地停车场，节假日景区车位紧张可停外围换乘；电车提前规划沿途充电桩 |
| 火车 | 12306 提前 15 天放票，抢不到立刻挂候补；高铁 5 小时圈内优先火车 |
| 飞机 | 航旅纵横看航班动态与准点率；廉航注意行李额度 |
| 市内 | 地铁 + 步行为主；去偏远景点提前查好末班车时间，自驾的话先查好停车场 |

## 三、住宿

- 位置优先：靠近地铁站或赛事起点，省下的时间比房费值钱
- 提前 1~2 周订，节假日越早越好，比赛的话报完名就可以订了，不然抢不到的
- 先订「可免费取消」的房型占坑，行程确定后再换更划算的

## 四、行李清单

- **证件**：身份证、~~学生证（如果是学生的话）~~
- **电子**：充电宝（必须随身，不能托运）、充电线、相机
- **衣物**：速干衣、轻薄外套、一双舒服的鞋
- **跑步 / 比赛**：跑鞋、比赛装备、号码布、能量胶、盐丸
- **其他**：雨伞或雨衣、防晒霜、常用药、少量现金、登山杖

## 五、实用 App

- **地图**：高德 / 百度地图（公交、地铁、步行路线）
- **交通**：12306、航旅纵横
- **吃住**：大众点评、美团
- **天气**：墨迹天气
- **足迹**：每到一个城市，在 [探索地图](/travel/map) 的 `cityList` 里把次数 +1

## 六、旅行记录

1. 照片按日期归档，重要的地点随手记下来
2. 回来把走过的城市更新到 [探索地图](/travel/map)，颜色会随探索次数变深
3. 挑印象最深的写一篇游记
